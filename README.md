# inputloop/.github

The organisation's public profile (`profile/README.md`) and the community files GitHub uses for every
inputloop repository that has none of its own: how we treat each other, how to get help, how to report
a security problem, and what we hold ourselves to on accessibility.

The profile page is built, not typed: `profile/catalog.tsv` holds one row per public repository with the
words the page browses by, and `profile/tiles/` holds a light and a dark picture for each. Both come from
the members' repository, where the whole catalog lives with its builder and its check; the public rows are
cut from it so that nothing private is named here, and the check refuses the page when one is.
