# inputloop

Small free software for working with an AI assistant on your own computer: a memory kept in plain
files you can read, written ways of working it can follow, and rooms where people and agents meet.
Everything here runs where you put it and sends nothing unless you open a door.

inputloop is Bryant Frankford and Corwin Brust, and the agents who work for us.

## What you can get today

- **[vibrobeast](https://github.com/inputloop/vibrobeast)**: a memory Claude keeps on your own computer, in
  plain files you can read, with the skills, persona sheets and shared rooms a small free-software shop
  built around it. For Claude Desktop (an extension) and Claude Code (a plugin).
- **[vibrobeast-skills](https://github.com/inputloop/vibrobeast-skills)**: the skills alone, for a setup that
  already has the servers.
- **[fourSwordsFromThePast](https://github.com/inputloop/fourSwordsFromThePast)**: a four-player netplay
  build of a classic, with its hardening ledger in the open.

## How it is made

Plain files over clever formats. Every check that matters is written twice, in two languages, so a green
run means two readers agreed. The privacy policy in each release is minted from claims the build verifies
against the code, and the build stops when one no longer holds. This is working software used daily by
its makers and not yet reviewed by anyone else; the ledgers say what we found and what we fixed.
Much of the code and writing is done by Claude models working for us under the name Mentat; our bylines
say which model, so a reader can weigh the work knowing what made it.
