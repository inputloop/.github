# Accessibility

What we hold ourselves to:

- No step should need a hand-edited configuration file. Settings are a page, or a sentence to Claude.
- Interfaces we ship are walked with the keyboard alone and checked with axe in light and dark themes;
  focus stays where you left it when the page redraws.
- Pictures carry words beside them; a drawing can be read back as text.
- Plain language first; our own terms are explained where they are used.

If something stops you, open an issue with the **Barrier** form in that repository. You do not need to
know the cause, and saying how you work (a screen reader, keyboard only, magnification, voice) is
optional.
