# Security

Please report a vulnerability privately to **BryantAndCorwin@inputloop.com**, not in a public issue;
both of us read it. To encrypt, use Corwin's OpenPGP key
`ECE7 7CF4 17C7 6C1A CFCE 7C2B 5B61 3551 1580 F007` (on keys.openpgp.org).
Say what you found, how to reproduce it and what it lets someone do. A person replies; with two
maintainers, allow a few days. A repository's own SECURITY.md, where there is one, says what is in scope.
